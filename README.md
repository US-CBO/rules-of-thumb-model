# CBO's Rules of Thumb Model

CBO has long published “rules of thumb” that provide an idea of how changes in key economic variables would affect its projections. The rules of thumb model allows users to define and analyze alternative economic scenarios by specifying differences in the values of four economic variables—productivity growth, labor force growth, interest rates, and inflation—relative to the values underlying CBO’s most recent projections. Those projections were published in [The Budget and Economic Outlook: 2026 to 2036](https://www.cbo.gov/publication/61882). The model here supplements CBO’s report on [How Changes in Economic Conditions Might Affect the Federal Budget: 2026 to 2036](https://www.cbo.gov/publication/62257) and replicates the interactive on line tool found here: [How Changes in Economic Conditions Might Affect the Federal Budget, 2026 to 2036: An Interactive Tool](https://www.cbo.gov/publication/61914).

## How to download the model
The model was created in Microsoft Excel. The data, logic, and documentation for the model are contained in a single file, which you can download here: [rules-of-thumb-model.xlsx](https://github.com/US-CBO/rules-of-thumb-model/raw/refs/heads/main/rules-of-thumb-model-2026.xlsx). After downloading the model, you can find the Excel file, `rule-of-thumbs-model.xlsx`, in your `Downloads/` directory and open it. The first worksheet in the workbook contains a more detailed README with instructions on how to use the model.

For more details on the interactive scenarios and limitations for using them, see How Changes in Economic Conditions Might Affect the Federal Budget, 2026 to 2036: An Interactive Tool (linked above).
